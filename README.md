## 📋 Название проекта и описание:

Этот проект представляет собой упрощённую модель интернет-магазина,
реализованную на Python. В нём демонстрируются основы объектно-ориентированного
программирования: классы, наследование, инкапсуляция, магические методы, 
свойства (property), класс-методы и статические счётчики. 
Проект содержит модули для работы с товарами и категориями, 
а также специализированные виды товаров: смартфоны и газонную траву. 
Код покрыт тестами с использованием pytest.

## 📋 Возможности

1. Создание товаров с названием, описанием, ценой и количеством. 
2. Управление ценой товара с проверкой на отрицательные значения
   и запросом подтверждения при понижении цены. 
3. Группировка товаров в категории. 
4. Возможность подсчёта суммы сложения двух продуктов одного класса 
   в зависимости от количества на складе и стоимости. 
5. Поддержка двух специализированных типов товаров: 
   Smartphone (добавлены характеристики: производительность, модель, память, цвет)
   и LawnGrass (страна-производитель, срок прорастания, цвет). 
6. Магические методы __str__ для красивого вывода и 
   __add__ для расчёта общей стоимости товаров на складе. 
7. Класс-метод new_product для создания товара из словаря. 
8. Класс-метод add_product для добавления только продуктов. 
9. Полное тестирование всех ключевых функций с помощью pytest.

## 📋 Описание классов

### Product (src/product.py)

Базовый класс для любого товара.
#### Атрибуты:
```
name (str): название товара
description (str): описание
__price (float): цена (приватный атрибут, доступ через property)
quantity (int): количество на складе
```
#### Методы:
```
__init__(name, description, price, quantity): конструктор
new_product(cls, dict): класс-метод для создания товара из словаря
price.getter: возвращает цену
price.setter: позволяет изменить цену с проверкой (при понижении запрашивает подтверждение)
__str__(): строковое представление товара
__add__(other): складывает стоимость двух товаров (price * quantity), типы должны совпадать
```

### Category (src/category.py)

Класс для категории товаров.
#### Атрибуты:
```
category_count: общее количество созданных категорий
product_count: общее количество товаров во всех категориях
```
##### Атрибуты экземпляра:
```
name (str): название категории
description (str): описание
__products (list): приватный список товаров в категории
```
#### Методы:
```
__init__(name, description, products): конструктор, увеличивает счётчики
add_product(product): добавляет товар в категорию (проверяет тип)
products.getter: возвращает строку со списком товаров (каждый товар с новой строки)
__str__(): возвращает название категории и общее количество товаров на складе
```

### Smartphone (src/smartphone.py)

Наследник Product, добавляет характеристики смартфона.
#### Дополнительные атрибуты:
```
efficiency (float): производительность
model (str): модель
memory (int): объём памяти (ГБ)
color (str): цвет
```

### LawnGrass (src/lawngrass.py)

Наследник Product, добавляет характеристики газонной травы.
#### Дополнительные атрибуты:
```
country (str): страна-производитель
germination_period (str): период всхожести
color (str): цвет
```

## 📋 Запуск и примеры использования
Запуск 
```
from src.product import Product
from src.category import Category
from src.smartphone import Smartphone
from src.lawngrass import LawnGrass

# Создание товаров
product1 = Product("Ноутбук", "Мощный ноутбук", 75000, 3)
product2 = Product("Мышь", "Беспроводная мышь", 1500, 10)

# Создание категории
category = Category("Электроника", "Товары для работы и дома", [product1, product2])
print(category)
# Электроника, количество продуктов: 13 шт.

# Добавление нового товара
product3 = Product("Коврик для мыши", "Игровой коврик", 800, 5)
category.add_product(product3)
print(category.products)
# Ноутбук, 75000.0 руб. Остаток: 3 шт.
# Мышь, 1500.0 руб. Остаток: 10 шт.
# Коврик для мыши, 800.0 руб. Остаток: 5 шт.

# Работа с ценой (подтверждение понижения)
product1.price = 70000  # если цена ниже, запросит подтверждение

# Сложение товаров (общая стоимость на складе)
total_cost = product1 + product2
print(total_cost)  # 75000*3 + 1500*10 = 225000 + 15000 = 240000

# Создание товара из словаря
data = {"name": "Книга", "description": "Учебник", "price": 500, "quantity": 2}
book = Product.new_product(data)

# Создание специализированных товаров
phone = Smartphone("iPhone 14", "Смартфон Apple", 90000, 7, 90.0, "14 Pro", 128, "серебристый")
grass = LawnGrass("Газон", "Для дачи", 2000, 15, "Россия", "7-10 дней", "зелёный")
```

## 📖 Тестирование

Проект покрыт тестами pytest.
1. Запуск всех тестов:
```
pytest
```
2. Запуск с детальным выводом:
```
pytest -v
```
3. Запуск конкретного тестового файла
```
pytest tests/test_widget.py
```
4. Запуск конкретного теста:
```
pytest tests/test_widget.py::test_get_date -v
```
5. Запуск с покрытием кода:
```
pytest --cov=src --cov-report=html
```
6. Создание отчета о проверке:
```
poetry run pytest --cov
```
7. Расположение отчета в HTML-формате: 
```
В папке 'htmlcov' в модуле 'index.html'
```
