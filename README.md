Описание:
E-commerce  — электронная торговля, или электронная коммерция. 
На основе этого проекта планируется реализация истемы платежей, на основе ядра для интернет-магазина. 
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

## Классы

### `Product`
- **Атрибуты**: `name` (название), `description` (описание), `price` (цена), `quantity` (количество).
- **Методы**: конструктор `__init__`.

### `Category`
- **Атрибуты экземпляра**: `name`, `description`, `products` (список товаров).
- **Атрибуты класса**: `category_count` (количество созданных категорий), `product_count` (общее количество товаров во всех категориях).
- **Методы**: конструктор `__init__`, который автоматически увеличивает счётчики категорий и продуктов.

## Установка и запуск тестов

1. **Клонируйте репозиторий** (если ещё не сделано).
2. **Создайте виртуальное окружение** (рекомендуется) и активируйте его.
3. **Установите зависимости**:

   pip install pytest pytest-cov
   pip install -r requirements.txt
### Запуск тестов:

Все тесты:
  pytest

С подробным выводом:
  pytest -v

С измерением покрытия кода:
  pytest --cov=src --cov-report=html    #Отчёт появится в папке htmlcov/.

## Пример использования

  from src.category import Category
from src.product import Product

# Создаём товары
p1 = Product("Iphone 15", "512GB, Gray space", 210000.0, 8)
p2 = Product("Xiaomi Redmi Note 11", "1024GB, Синий", 31000.0, 14)

# Создаём категорию с товарами
category = Category("Смартфоны", "Мобильные телефоны", [p1, p2])

# Проверяем счётчики
print(Category.category_count)   # 1
print(Category.product_count)    # 2

## Тестирование
Проект покрыт тестами, которые проверяют:

Корректность инициализации объектов.

Поведение при отсутствии списка товаров (по умолчанию пустой список).

Правильность подсчёта категорий и продуктов через атрибуты класса.

Тесты находятся в папке tests/ и используют фикстуры для подготовки данных.
